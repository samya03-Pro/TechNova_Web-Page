# Nyra — Responsive Landing Page

A modern, fully responsive landing page built for **Task 3: Responsive Landing Page** of the TechNova Web Development Internship.

## 📁 Project Structure
```
├── index.html      # Page markup (Hero, About, Services, Contact, Footer)
├── style.css        # All styling, layout, and responsive breakpoints
├── script.js         # Interactivity: mobile menu, scroll reveal, back-to-top, form
└── README.md
```

## ✨ Features
- **Sections included:** Hero, About, Services, Contact — as required by the task brief
- **Fully responsive** — tested down to small mobile screens with a collapsible hamburger menu
- **Hover effects** on buttons (animated arrows), nav links, and service/highlight cards (lift + glow)
- **Smooth scrolling** for all in-page navigation links
- **Scroll-reveal animations** as sections come into view
- **Working contact form** (client-side only, with validation and a confirmation message)
- **Back-to-top button** that appears after scrolling
- **Accessible:** visible keyboard focus states, `prefers-reduced-motion` respected

## 🎨 Design
- **Colors:** Deep near-black green background with a lime-green (`#b7f556`) accent and teal (`#5fd9c4`) highlights
- **Typography:** Space Grotesk (display) + Inter (body), loaded via Google Fonts
- **Layout:** Sticky nav → hero with layered wave graphic + highlight cards → about section → 3-card services grid → contact form → footer

## 🛠️ Built With
- HTML5
- CSS3 (Flexbox, Grid, custom properties, media queries)
- Vanilla JavaScript (no frameworks or libraries)

## 🚀 How to Run
1. Download / clone this repository
2. Open `index.html` directly in any browser — no build step or server required
